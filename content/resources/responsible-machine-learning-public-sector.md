Machine learning can scale decisions that affect people's access to housing,
benefits, and justice. This guide examines the technical and social pitfalls —
biased training data, opaque models, and feedback loops — and how to mitigate
them.

You'll learn to run algorithmic impact assessments, choose appropriate fairness
metrics, and build meaningful human oversight into deployed systems.
